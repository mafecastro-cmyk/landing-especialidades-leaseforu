## Configurar el redirect del formulario

Cuando montes el modulo del form en la landing de ginecologia, configura el redirect:

**Marketing > Formularios > RO_01 Formulario general > Editar** > pestana **Opciones** > **Redireccionamiento despues de enviar** > URL de esta thank you page (ej. `https://leaseforu.com/lp-gracias-ginecologia`).
